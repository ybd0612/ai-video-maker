## 二、关键问题与优化建议

### 🔴 P0 - 必须修复

#### 2.1 用户体验：无加载反馈
**问题**：脚本生成耗时 2-5 秒，但用户无任何提示  
**影响**：用户以为卡死，反复点击"生成分镜"按钮  
**建议**：
```tsx
// 在 generateScript 调用处添加 loading 状态
const [isGenerating, setIsGenerating] = useState(false);
<button disabled={isGenerating} onClick={handleGenerate}>
  {isGenerating ? <Loader2 className="animate-spin" /> : null}
  生成分镜
</button>
```
**优先级**：高（影响核心工作流）

---

#### 2.2 数据丢失风险
**问题**：刷新页面后 localStorage 数据丢失，无自动保存机制  
**影响**：用户生成到一半的项目消失，体验极差  
**建议**：
- 方案 A：使用 IndexedDB 替代 localStorage（容量更大、异步）
- 方案 B：定期 `setInterval(() => store.persist.persist(), 30000)` 显式保存
- 方案 C：首次加载时检测 localStorage 是否有数据，无则提示从云端恢复

**优先级**：高（数据安全第一）

---

#### 2.3 视频生成时间预估缺失
**问题**：视频生成 30-90 秒，但用户不知道要等多久  
**影响**：用户焦虑、重复提交任务  
**建议**：
```
预估时间 = num_frames / fps × 2倍
例：81帧/24fps ≈ 3.4秒 → 预估 7-10 秒
```
在 UI 显示进度条 + 文字提示"预计还需 XX 秒"

**优先级**：中（可缓解焦虑）

---

### 🟡 P1 - 重要改进

#### 2.4 多项目管理缺失搜索/筛选
**问题**：项目数量 > 10 后，左侧列表无法搜索/按日期排序  
**影响**：用户难以找到目标项目  
**建议**：
- 搜索框：按标题模糊匹配
- 排序选项：按更新时间倒序/正序
- 分组：按创建日期（今天/昨天/本周/更早）

**优先级**：中（提升导航效率）

---

#### 2.5 错误提示不明确
**问题**：API 429 仅显示"请求失败"，无具体时间窗口提示  
**影响**：用户不知道还要等多久，可能反复尝试触发更多 429  
**建议**：
```typescript
// rateLimit.ts 中增加人性化时间提示
const fmtReset = (ms: number): string => {
  if (ms < 60000) return `${Math.ceil(ms / 1000)} 秒`;
  if (ms < 3600000) return `${(ms / 60000).toFixed(1)} 分钟`;
  return `${(ms / 3600000).toFixed(1)} 小时`;
};
```

**优先级**：中（改善错误处理）

---

#### 2.6 不支持批量生成
**问题**：只能逐个分镜生成图片/视频  
**影响**：6 个分镜需点 6 次"生成图片"，效率低  
**建议**：
- 批量按钮："生成全部图片" / "生成全部视频"
- 并发度控制：默认 3（当前配置），用户可调整
- 批量进度条：显示 X/Y 已完成

**优先级**：中（提升生产效率）

---

#### 2.7 下载功能缺失
**问题**：最终视频生成后，只能预览不能下载  
**影响**：用户无法导出作品  
**建议**：
- FinalPreview.tsx 添加"下载 MP4"按钮
- 使用 `<a download>` 或 FFmpeg.wasm Blob URL 下载
- 支持下载封面图片

**优先级**：高（核心交付物）

---

### 🟢 P2 - 增强体验

#### 2.8 缺少示例项目/模板
**问题**：新用户面对空白界面不知道如何开始  
**影响**：首屏流失率高  
**建议**：
- 提供 3-5 个示例项目（旅游 vlog、产品介绍、故事短片）
- 每个示例预填好提示词 + 分镜结构
- 用户点击"使用模板"一键复制

**优先级**：低（新手引导）

---

#### 2.9 无协作/分享功能
**问题**：项目只能本地存储，无法分享给他人编辑  
**影响**：团队协作受阻  
**建议**：
- 导出项目为 JSON 文件（含所有分镜/资产）
- 导入项目 JSON
- 未来可选：云端同步（需后端支持）

**优先级**：低（协作场景）

---

#### 2.10 模型选择受限
**问题**：文本仅支持 agnes-2.5-flash，用户无法选择 2.0-flash 或其他模型  
**影响**：高级用户可能希望切换模型  
**建议**：
- 设置对话框添加模型选择下拉
- 默认展示"推荐"标签（2.5-flash 推荐）
- 不同模型的价格/速度信息提示

**优先级**：低（扩展性）
