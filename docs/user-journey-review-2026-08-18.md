## 二、P1：应优先修复

### 1. 异步任务没有统一绑定发起项目 ID

**影响**：用户在生成资产、分镜、图片或视频期间切换项目，结果可能写入当前错误项目。

**涉及位置**：
- `src/features/wizard/useWizardActions.ts`
- `src/features/wizard/StepStoryboard.tsx`
- `src/pages/ProjectWorkspace.tsx`

**典型复现**：项目 A 启动生成 → 切换到项目 B → 请求返回。当前多个异步路径仍调用基于 `activeProjectId` 的 `updateShot` / `setShotStatus` / `setProjectStatus`。

**建议**：统一提供 `updateShotByProjectId(projectId, shotId, updates)`、`setProjectStatusById(projectId, ...)` 等 store API；所有异步操作在启动时捕获 `targetProjectId`，完成、失败、进度回调均使用目标 ID，不再依赖当前活动项目。

### 2. “最终预览/下载”存在死代码与主流程重复

当前主流程 `CreationWizard` 第 6 步渲染 `StepAssembly`，而 `FinalPreview` 在项目中没有实际 import/使用点。两个组件都实现拼接和下载，导致错误提示、下载逻辑和 Blob 生命周期修复可能只落在未使用的组件上。

**建议**：二选一，推荐保留 `StepAssembly` 作为唯一最终交付页面，删除或合并 `FinalPreview`；把错误提示、完整性校验、Blob URL 释放、重新生成入口统一到唯一组件。

### 3. 产品优化报告已过时，容易误导后续迭代

`docs/product-optimization.md` 仍写着“无加载反馈”“数据丢失”“下载缺失”“IndexedDB 待实现”，但源码已具备 loading、Zustand localStorage 持久化和 StepAssembly 下载；报告末尾还把已完成事项写成“下一步建议”。

**建议**：将旧报告标记为历史基线，或直接同步为当前状态，避免团队按过时 P0 清单重复开发。

## 三、P2：流程与体验问题

### 4. 第 6 步允许部分视频拼接

`StepAssembly` 用 `videoShots = shots.filter(videoUrl)`，只要有一个视频就允许拼接，并会静默跳过缺视频镜头。正常向导虽会限制进入，但异常导航或状态恢复仍可能输出缺镜头成片。

**建议**：只有 `videoShots.length === shots.length` 才允许拼接；否则显示缺失镜头编号和“返回视频生成”按钮。

### 5. 切换项目后成片状态与 Blob 生命周期需严格隔离

`FinalPreview` 的 `renderedUrl` 是组件本地状态，没有随项目或镜头变化清空，也没有释放 Blob URL；若未来接入该组件，会出现旧项目视频配新项目标题下载、重复渲染内存增长等问题。`StepAssembly` 已有卸载释放，但没有按项目/镜头变更清空旧结果。

**建议**：为成片计算 `renderSignature = project.id + shot video URLs`；项目或签名变化时撤销旧 URL 并清空预览。

### 6. “清除项目”按钮实际删除项目

`ProjectWorkspace` 的 `handleClear` 调用 store 的 `clearProject`，而 store 实现是从 `projects` 数组移除当前项目。按钮文案“清除项目”容易被理解为清空内容，而非删除整个项目。

**建议**：改为“删除项目”，二次确认文案明确列出项目名和不可恢复范围；如果要保留“清空内容”，另设真正的清空动作。

### 7. 本地拼接代理对 localhost 不兼容

`renderService.ts` 当前只在 hostname 为 `127.0.0.1` 时走 CDN 代理；用常见的 `localhost` 打开开发环境时可能直接请求远程视频，触发 CORS，导致 FFmpeg 拼接失败。

**建议**：同时支持 `localhost` 与 `127.0.0.1`，并在拼接失败时给出“远程视频跨域/代理不可用”的明确提示。

### 8. 控制台存在 404 资源错误

本轮隔离浏览器加载首页后发现 1 条 `Failed to load resource: 404 (Not Found)`。页面主体仍正常，但应定位具体 URL，避免 favicon、静态资源或 API 请求错误被隐藏。

## 四、流程体验建议

1. **生成期间项目切换**：显示“任务属于项目 A”，切换时提示“任务仍在后台运行”，提供取消或继续查看入口。
2. **步骤导航**：在第 2 步“跳过资产”后明确说明会跳过角色/场景参考图，而不是只显示一个跳过按钮。
3. **错误恢复**：每个失败镜头应提供“重试本镜头”和“查看失败原因”；限流错误应禁用重复重试直到 reset 时间到达。
4. **完成态**：成片生成完成后提供“下载 MP4”“重新拼接”“返回修改分镜”三个明确动作。
5. **空状态**：项目列表、分镜列表、成片列表的空状态应给出下一步 CTA，而不是只显示说明文字。
6. **密钥安全**：本轮只在隔离浏览器上下文写入测试 Key，走查结束已清除；生产环境建议继续避免把 Key 写入测试报告、日志或截图。
